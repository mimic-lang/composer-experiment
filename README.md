# mimic-compat/parking

Placeholder package that reserves the `mimic-compat` vendor namespace on
[Packagist](https://packagist.org/).

It ships no code, no autoloader and no dependencies — installing it does nothing.
Do not add it to your project.

The vendor is reserved for future compatibility packages that let the PHP
ecosystem consume [Mimic](https://github.com/mimic-lang) as an ordinary
Composer dependency.
